# Source file inventory

The intended public source set includes `.github/workflows/` and `src/` (including synthetic regression fixtures), `e2e/`, `scripts/`, `docs/` (including the XML example), `README.md`, `index.html`, `package.json`, `package-lock.json`, `.nvmrc`, `.gitignore`, and the root TypeScript, Vite, Vitest, Playwright and ESLint configuration files. The project [LICENSE](../LICENSE) grants reuse under MIT, copyright 2026 Denissvgn, including the project-authored examples and fixtures. Public visibility alone is not a reuse grant; the license supplies the terms. Third-party components retain their respective licenses.

Generated bundles, installed dependencies, coverage, browser test output, `ci-results/` and local `reports/` are excluded. Local `.env*` files, `.npmrc`, private key/certificate containers and common credential filenames are also excluded. Only the exact `.env.example` and `.env.sample` names are exceptions; include them only with sanitized placeholders. No environment file is required to run this app. Do not put tokens in the committed package scripts, lockfile URLs or examples.

Ignore rules are a convenience, not a secret scanner: arbitrary filenames can still contain secrets, and already tracked files remain tracked. Review the complete outgoing file list and staged diff before committing; inspect history before publishing. Repeat ignore checks against the actual index when repository initialization is complete. Do not force-add private reports or credentials. The [source and dependency license scope](license-scope.md) distinguishes this source tree from distributions containing installed packages or bundled code. Those distributions need their own component and notice review.
